## 一、页面流转图（文字版，正式稿替换为draw.io导出图）

```
登录页(1.0既有)
   │ admin/监管账号登录（X-Access-Token）
   ├──→ 大屏页 /screen/main（1920×1080全屏，新增）
   │       ├─→ 点击地图点位 → 点位气泡（企业名/最新浓度/状态）
   │       ├─→ 点击榜单企业 → 明细抽屉（信用得分/扣分明细，UC-E03扩展流）
   │       └─→ 轮播开关 → 分区轮播（SHOULD）
   ├──→ 信用规则配置页 /credit/rule（Web管理端，新增，1.0三段式）
   │       └─→ 新增/编辑弹窗 → 保存（UC-E04）
   └──→ 信用公示页 /credit/public（Web端，新增）
           └─→ 点击企业 → 单企业等级与明细（UC-E05）

（消灭"页面孤岛"检查：以上5个节点均可达、均可返回；大屏为只读展示无回退操作，Esc退出全屏回管理端）
```

**布局规格**：CSS Grid 三行（顶栏72/内容792/底栏64）+中带96px告警条；左区1140×792、右上420×404、右下420×388；间距16px；内部卡片化（ChartCard）。ScreenContainer 以1920×1080为基准 transform:scale 等比缩放（#E-16），超宽屏两侧留深色底不拉伸。

**配色**：底色 #0a1a2f 系（卡片 #10263f / 描边 rgba(24,144,255,.25)）；强调/选中 #1890FF；语义色 红#f5222d 黄#faad14 绿#52c41a 仅用于信用牌与告警等级；正文 rgba(255,255,255,.85)。

## 三、每区数据来源与刷新（含权限标注）

| 区块 | 组件/图表选型 | 数据来源（接口） | 刷新 | 权限 |
|---|---|---|---|---|
| 顶栏 | 原生+时钟 | 系统时间+轮播参数(1.0系统参数) | — | dashboard:screen:view |
| 左区地图 | vue-baidu-map 0.21.22（复用1.0）+ BMapLib HeatmapOverlay 热力扩展；>200点启用点聚合 | E-02接口（改造/home/getEquipmentPoint） | 随聚合周期 | 同上 |
| 告警滚动条 | 自研无缝滚动组件（#E-26，requestAnimationFrame+IntersectionObserver防后台空转） | E-03接口（getNewRisk口径） | 峰谷轮询 | 同上 |
| 趋势折线 | ECharts line（areaStyle渐变，#1890FF主色） | /v2/stat/alarm-trend | 随聚合周期 | 同上 |
| 行业饼图 | ECharts pie（环形，图例滚动） | /v2/stat/industry | 随聚合周期 | 同上 |
| 处理率仪表 | ECharts gauge | /v2/stat/process-rate | 随聚合周期 | 同上 |
| 信用榜 | 自研榜单组件（三段牌色分组，虚拟滚动） | /v2/credit/board | 周期后刷新 | 同上 |
| 底栏卡片 | a-card深色定制版 | 聚合接口regionOverview分区 | 随聚合周期 | 同上 |

**热力图选型结论（#E-20前置决策，W3定案）**：BMapLib.HeatmapOverlay（百度原生，与1.0底座零集成成本）为**主案**；ECharts+bmap 组合为备选（若需 ECharts 视觉统一再切换）。原型阶段双方案各渲50点对比截图，取舍理由写入设计说明书。

**统一轮询service（#E-25，吴一萱）**：全屏唯一轮询入口——按峰谷参数（峰30s~1min/谷≤5min）调聚合接口一次，分发五区；组件只订阅不自行请求；`beforeDestroy` 反注册+图表 `dispose`（稳定性NFR"8小时无泄漏"的实现载体）。

## 四、管理页原型说明（沈福临#E-46/47执行依据）

- **信用规则配置页**：严格1.0三段式——`a-card(borderless)` → `.search-header`（规则名称模糊+类型/状态下拉）→ a-table（列：指标代码/名称/类型dictText/分值/权重/周期/状态tag/操作）→ 操作列（编辑/启停/删除，v-has 控制）→ JModal 表单弹窗（rules校验+编辑回显）。
- **信用公示页**：同三段式，列=企业名/等级tag(红黄绿)/总分/周期/发布时间；等级列用语义色 tag。
- 两页均通过1.0菜单管理注册（组件路径+权限标识+角色分配），演示与1.0菜单无缝融合。

## 五、空态/加载/降级三态规范（体验五查落地）

| 状态 | 视觉 | 触发 |
|---|---|---|
| 加载 | ChartCard 内 a-spin | 首次/刷新请求中 |
| 空态 | 图标+"暂无数据/无超标热力"文案 | 接口返回空数组 |
| 降级 | 缓存数据+右上角「降级模式」黄标 | 请求失败/超时3s；自动重试 |
